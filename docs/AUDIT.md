# 安全审计记录

本项目在 `v0.1.0` 发布前完成了**三轮独立安全审计**：后端、前端各两轮，第三轮针对新增的访问密码
功能做终验；容器与 CI 另经两轮复核。

审计由多名独立审计员分别执行，**每轮都以上一轮的修复为输入**，重点验证「修复是否真的生效」而非
只看代码改动。所有结论均来自实际执行的命令、真实进程实测或真实浏览器断言。

审计的详细报告未包含在本仓库中（其中含审计环境与内部路径细节）；本文是面向使用者的公开摘要。

## 关键修复

### 认证与授权

- **`X-Forwarded-For` 限流绕过**（High）：原实现取最左值，同机反向代理部署下攻击者可伪造该头
  无限重置限流桶，进而无限制消耗运营者的上游 API 额度。修复为**只信任最右跳**、末值非法时回退直连
  对端，并按 IPv6 `/64` 归并。实测伪造最左值轮换 40 次仍在第 31 次返回 `429`。
- **Host 头未校验**（High）：绑定非回环地址时缺少 Host 校验，存在 DNS rebinding 风险。新增可选
  `ALLOWED_HOSTS` 白名单；实测 `Host: evil.example` → `403`。
- **访问密码实现缺陷**（第三轮）：登录密码长度按字节校验、生成按字符校验，导致**非 ASCII 密码可生成
  但永远无法登录**；`--hash-password` 提示输出的配置行未加引号，直接写入 `.env` 会被 dotenvy 变量
  展开导致启动失败；这两项均已修复并加回归测试。
- **登录并发资源放大**（Medium）：Argon2 校验在异步运行时中同步执行，并发登录可阻塞 worker 并推高
  内存。已移入阻塞线程池并加全局并发上限，过载时返回可重试的 `429`。

### 输入与网络

- **SSRF 绕过**（High）：修复前仅做字面量主机检查，IPv6 内嵌 IPv4、6to4、Teredo、NAT64、单标签
  域名、保留网段等 **33 个变体**可绕过。现已全部封堵并建立回归用例。
- **panic 放大**（High）：release profile 的 `panic = "abort"` 会让 `CatchPanicLayer` 失效，任一
  panic 直接终止服务进程。已移除该配置，实测 panic 被转成 `500` 且进程存活。
- **密钥泄露**：畸形 `.env` 解析错误会把含真实 API Key 的整行打印到日志；已改为脱敏输出。

### 前端

- **XSS**：`javascript:` / `data:` / `vbscript:` / 内联 HTML / SVG / mXSS 等 **31 组 payload**
  在 Markdown 渲染链路实测全部被拦截；配合严格 CSP（无 `unsafe-inline` / `unsafe-eval`）。
- **对比度与触控**：浅色主题 53 处、深色主题 47 处对比度不达 WCAG AA；375px 下 301 处触控目标
  小于 44px。修复后两个主题与触屏均 **0 处**不达标。
- **门禁首屏闪烁**（Medium）：未通过密码验证时，搜索框会先于密码框渲染 2 帧。已改为配置未知时只
  渲染骨架。
- **401 回退**：搜索或抓取返回 `401` 时统一清除 token、关闭浮层并回到密码门禁。

## 验证方式

审计不只看代码，包含以下可复现的验证手段：

| 手段 | 用途 |
|---|---|
| RFC 4231 官方测试向量 | 验证手写 HMAC-SHA256 实现（覆盖 >64 字节长密钥分支） |
| 独立实现交叉验证 | 用另一语言独立推导签名密钥伪造 token，确认服务端接受/拒绝行为一致 |
| 真实进程 + 原始 socket | 伪造重复头、畸形请求、半开连接、超长报文 |
| 真实浏览器（CDP） | CSP 实际拦截、焦点陷阱、竞态、伪造 token 回退、响应式溢出 |
| 只读容器内实测 | distroless + 只读根文件系统 + 非 root 下跑完整搜索/抓取/鉴权链路 |
| `cargo audit` | 250 个依赖、1338 条安全公告，0 漏洞 |
